Automation that stays on your phone.

Latch is a privacy-first Tasker-style app for Android. Build local if/then rules, profiles, and recipes — no account, no cloud, no trackers. Optional Shizuku when you need more.

Free & open source · MIT · Android 8+

Built for real day-to-day rules

Sticky monitor, clear permissions, and controls that make sense — sliders, Wi‑Fi pickers, and profiles.

Sticky rules

Foreground monitor + watchdog so automations keep listening after hours, not only while the UI is open.

Triggers that fit

Battery, time windows, Wi‑Fi SSID, app focus, and more — with multi-action rules and edge detection.

Privacy first

No telemetry, no account. Optional Shizuku / root only when you enable elevated actions.

Material You

Light, dark, system, AMOLED, and seed colors — the same care as modern Android system apps.

Recipes

Import and export plain JSON recipes. Share automations without a proprietary cloud.

Profiles & variables

Home / Work / Sleep profiles and tokens like %battery and %ssid inside actions.
