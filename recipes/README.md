# Latch recipe packs

Import any JSON file from the app (**Import rules**) or merge the `rules` array into an export.

| File | Idea |
|------|------|
| `battery_saver.json` | Dim brightness when battery is low |
| `sleep_focus.json` | Night / focus style rule |
| `work_wifi_silent.json` | Silent ringer on a work SSID |
| `headphones_music.json` | Open music app on headphone connect |
| `charging_notify.json` | Notify when charging starts |
| `night_dnd.json` | Silent between 22:00 and 07:00 |
| `boot_welcome.json` | Notify after boot |

Edit SSID, packages, and times before relying on a recipe.
